# Tech stack icons

The development and design SVG logos are sourced from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons).
The original single-color shapes are preserved and recolored white, with transparent
backgrounds and 35 × 35 display dimensions.

HTML and CSS use the `html5-plain` and `css3-plain` assets. Sass, React, Redux,
Tailwind CSS, GitHub, and Vercel use `original`; Less uses `plain-wordmark`; all other logos
use `plain`.

Devicon's MIT license is included in `LICENSE.txt`. Brand names and logos belong
to their respective owners.

`codex.svg` is the monochrome Codex logomark from
[@lobehub/icons-static-svg v1.95.1](https://unpkg.com/@lobehub/icons-static-svg@1.95.1/icons/codex.svg).
Lobe Icons' MIT license is included in `LOBE-ICONS-LICENSE.txt`.

`openai.svg` preserves the OpenAI Blossom SVG path from the header of the
[official Codex documentation](https://developers.openai.com/codex/).
Both AI logos have white fills, transparent backgrounds, and 35 × 35 display
dimensions. The Codex and OpenAI marks belong to OpenAI; see the
[OpenAI brand guidelines](https://openai.com/brand/).

`contentstack.svg` contains the two symbol paths from Contentstack's
[official logo SVG](https://images.contentstack.io/v3/assets/blt77d44a06c81b1730/blt617067dddb390b21/68a5eefcf27901fe45ae92a5/New_Contentstack_Logo.svg),
as linked on its [homepage](https://www.contentstack.com/). The symbol retains its
original geometry and uses white fills, a transparent background, and 35 × 35px
display dimensions. The Contentstack mark belongs to Contentstack.
